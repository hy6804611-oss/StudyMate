💻 CHAPTER 2: HISTORY AND GENERATIONS OF COMPUTERS

The history of computers dates back to ancient times when humans used simple devices for counting and calculations. Over the years, computers have developed from large mechanical machines into small, fast and powerful electronic devices used worldwide.

History of Computers

Abacus – The earliest calculating device used for counting and basic arithmetic.

Napier's Bones – Invented by John Napier to perform multiplication and division.

Slide Rule – Used for mathematical calculations before electronic calculators.

Pascaline – Invented by Blaise Pascal to perform addition and subtraction.

Difference Engine – Invented by Charles Babbage to solve mathematical problems.

Analytical Engine – Also designed by Charles Babbage and regarded as the first general-purpose computer design.

Modern Computer – Developed using electronic components, making computers faster, smaller and more reliable.

Father of the Computer

Charles Babbage is known as the Father of the Computer because he designed the Analytical Engine, which became the foundation of modern computers.

Generations of Computers

First Generation (1940–1956) – Used vacuum tubes. They were very large, expensive, slow and generated much heat.

Second Generation (1956–1963) – Used transistors instead of vacuum tubes. They were faster, smaller and more reliable.

Third Generation (1964–1971) – Used Integrated Circuits (ICs). They were more powerful and consumed less electricity.

Fourth Generation (1971–Present) – Uses Microprocessors. Computers became very small, faster, cheaper and more efficient.

Fifth Generation (Present and Beyond) – Uses Artificial Intelligence (AI), robotics and advanced technologies that allow computers to learn and make decisions.

Features of Computer Generations

• Computers became smaller over time.

• Processing speed increased.

• Storage capacity improved.

• Reliability increased.

• Cost reduced.

• Power consumption became lower.

Importance of the Development of Computers

• Faster communication.

• Improved education.

• Better healthcare services.

• Easier banking and business operations.

• Advancement in science and technology.

• Automation of many daily activities.

💻 CHAPTER 7: COMPUTER MEMORY AND STORAGE DEVICES

Computer memory and storage devices are used to hold data, instructions and information. Some memory stores data temporarily while others store data permanently for future use.

Meaning of Computer Memory

Computer memory is the part of a computer used to store data, instructions and information for processing.

Types of Computer Memory

Primary Memory (Main Memory) – Memory directly accessed by the CPU. It stores data temporarily or permanently while the computer is operating.

Secondary Memory (Secondary Storage) – Used for permanent storage of data, programs and files.

Primary Memory

RAM (Random Access Memory) – Temporary memory that stores data currently being used. Its contents are lost when the computer is switched off.

ROM (Read Only Memory) – Permanent memory that stores important startup instructions. Its contents remain even after power is turned off.

Differences Between RAM and ROM

RAM – Temporary, read and write memory, loses data when power is off.

ROM – Permanent, mainly read-only memory, keeps data even when power is off.

Secondary Storage Devices

Hard Disk Drive (HDD) – Stores large amounts of data permanently.

Solid State Drive (SSD) – Faster and more reliable than HDD because it has no moving parts.

Flash Drive – Portable USB storage device.

Memory Card – Used in phones, cameras and tablets.

Compact Disc (CD) – Optical storage device.

Digital Versatile Disc (DVD) – Stores more data than a CD.

External Hard Drive – Portable device for backing up large amounts of data.

Importance of Storage Devices

• Store files permanently.

• Keep backup copies of important data.

• Make sharing files easier.

• Increase storage capacity.

• Protect valuable information.

• Support long-term record keeping.

Units of Computer Storage

Bit (b) – Smallest unit of data.

Byte (B) – Equal to 8 bits.

Kilobyte (KB) – Approximately 1,024 bytes.

Megabyte (MB) – Approximately 1,024 KB.

Gigabyte (GB) – Approximately 1,024 MB.

Terabyte (TB) – Approximately 1,024 GB.

Exam Tips

⭐ Know the difference between primary and secondary memory.

⭐ Memorize the differences between RAM and ROM.

⭐ Learn examples of storage devices.

⭐ Know the units of computer storage from Bit to Terabyte.

⭐ Understand the uses of HDD, SSD, Flash Drive, CD and DVD.

💻 CHAPTER 11: COMPUTER LANGUAGES

A computer language is a language used to communicate instructions to a computer. Since computers understand only machine language, programming languages are used to write programs that the computer can translate and execute.

Meaning of Computer Language

A computer language is a set of instructions and rules used to write programs that tell a computer what to do.

Types of Computer Languages

Machine Language – The first generation language written in binary digits (0s and 1s). It is the only language directly understood by the computer.

Assembly Language – The second generation language that uses mnemonics such as ADD, SUB and MOV. It requires an assembler to translate it into machine language.

High-Level Language – A programming language that is easy for humans to read and write. It requires a compiler or interpreter for translation.

Examples of High-Level Languages

• BASIC

• FORTRAN

• COBOL

• Pascal

• C

• C++

• Java

• Python

• JavaScript

• PHP

Language Translators

Compiler – Translates the whole program into machine language before execution.

Interpreter – Translates and executes one line of code at a time.

Assembler – Converts assembly language into machine language.

Advantages of High-Level Languages

• Easy to learn.

• Easy to write.

• Easy to debug.

• Portable across different computers.

• Faster software development.

Disadvantages of High-Level Languages

• Slower than machine language.

• Requires a compiler or interpreter.

• Uses more memory than machine language.

Exam Tips

⭐ Know the three main types of computer languages.

⭐ Differentiate between machine language, assembly language and high-level language.

⭐ Memorize examples of high-level programming languages.

⭐ Know the functions of a compiler, interpreter and assembler.

⭐ Machine language is the only language directly understood by the computer.

🔒 CHAPTER 22: COMPUTER SECURITY

Computer security refers to the protection of computer systems, hardware, software, networks and data from unauthorized access, theft, damage and cyber attacks. It helps ensure that information remains safe, confidential and available to authorized users.

Meaning of Computer Security

Computer security is the practice of protecting computers, networks and digital information from threats and unauthorized access.

Importance of Computer Security

• Protects personal information.

• Prevents unauthorized access.

• Protects business and government data.

• Reduces cybercrime.

• Prevents financial losses.

• Ensures safe internet usage.

Common Computer Threats

Virus – A malicious program that infects and damages files.

Worm – A program that spreads itself across computers without user action.

Trojan Horse – A harmful program disguised as useful software.

Spyware – Software that secretly collects users' information.

Ransomware – Malware that locks files and demands payment for their release.

Phishing – Fake emails or websites used to steal usernames, passwords and banking details.

Ways to Protect a Computer

• Install antivirus software.

• Use strong passwords.

• Update software regularly.

• Avoid opening suspicious emails or links.

• Back up important files regularly.

• Enable firewalls.

• Download software only from trusted sources.

Security Devices and Software

Antivirus – Detects and removes malware.

Firewall – Blocks unauthorized access to a computer or network.

Encryption – Converts data into a secret code to protect it.

Backup System – Creates copies of important data for recovery.

Cyber Safety Tips

• Never share your passwords.

• Log out of public computers.

• Verify websites before entering personal information.

• Avoid downloading unknown files.

• Keep operating systems updated.

• Report suspicious online activities.

Exam Tips

⭐ Know the meaning of computer security.

⭐ Differentiate between viruses, worms, Trojans and spyware.

⭐ Learn the functions of antivirus software and firewalls.

⭐ Understand phishing and ransomware attacks.

⭐ Memorize methods of protecting computers and personal data.
