📂 Map Scale and Distance

Map Scale

Scale = Map Distance / Ground Distance

📖 Meaning: Shows the relationship between distance on a map and the actual distance on the ground.

🎯 When to Use: Used to convert map measurements into real-world distances.

📝 Formula Rearrangement:

  • Map Distance = Scale × Ground Distance
  • Ground Distance = Map Distance ÷ Scale

💡 Memory Tip: Map is always a smaller representation of the real world.

⚠️ Common Mistake: Ensure both distances use the same unit before calculating.

Representative Fraction (RF)

RF = Map Distance / Actual Ground Distance

📖 Meaning: A numerical way of expressing map scale.

🎯 When to Use: Used when converting between map and ground measurements.

📝 Formula Example:

  • 1 : 50,000 means 1 unit on the map represents 50,000 units on the ground.

💡 Memory Tip: RF has no units because both sides use the same measurement.

⚠️ Common Mistake: Do not mix centimetres and kilometres without conversion.

Distance Conversion

Actual Distance = Map Distance × Scale Factor

📖 Meaning: Converts measured map distance into real distance.

🎯 When to Use: Used in map reading and topographic calculations.

📝 Common Conversions:

  • 100 cm = 1 m
  • 1000 m = 1 km

💡 Memory Tip: Always convert the final answer to the required unit.

⚠️ Common Mistake: Forgetting unit conversion causes wrong answers.

📂 Map Enlargement and Reduction

Scale Factor

Scale Factor = New Size / Original Size

📖 Meaning: Shows how much a map or drawing has been increased or decreased.

🎯 When to Use: Used when enlarging or reducing maps, diagrams, or photographs.

📝 Formula Rearrangement:

  • New Size = Scale Factor × Original Size
  • Original Size = New Size ÷ Scale Factor

💡 Memory Tip: Enlargement factor is greater than 1; reduction factor is less than 1.

⚠️ Common Mistake: Apply the scale factor to both length and width.

Area Change After Enlargement

New Area = Original Area × (Scale Factor)²

📖 Meaning: Shows how the area changes when a map is enlarged or reduced.

🎯 When to Use: Used for calculating changes in mapped areas.

📝 Formula Rearrangement:

  • Original Area = New Area ÷ (Scale Factor)²

💡 Memory Tip: Length uses scale factor, area uses scale factor squared.

⚠️ Common Mistake: Do not multiply area by the scale factor only.

Linear Scale Conversion

Ground Distance = Map Distance × RF Denominator

📖 Meaning: Converts a map measurement into the actual distance on Earth.

🎯 When to Use: Used with representative fraction scales.

📝 Formula Example:

  • 1 : 100,000 means 1 cm on map = 100,000 cm on ground.

💡 Memory Tip: The second number in RF is the multiplier.

⚠️ Common Mistake: Remember to convert the final answer to metres or kilometres.

Map Enlargement Percentage

% Increase = (New Size − Original Size) / Original Size × 100

📖 Meaning: Calculates the percentage increase in map size.

🎯 When to Use: Used to compare original and enlarged maps.

📝 Formula Rearrangement:

  • % Increase = Change in Size ÷ Original Size × 100

💡 Memory Tip: Percentage change is always compared with the original value.

⚠️ Common Mistake: Do not divide by the new size.

📂 Bearings and Direction

Bearing Angle

Bearing = Angle Measured Clockwise from North

📖 Meaning: Bearings show the direction of one place from another using degrees.

🎯 When to Use: Used in maps, navigation and surveying.

📝 Rules:

  • Always measured clockwise.
  • Written as three digits (e.g., 045°, 120°, 270°).
  • North = 000° / 360°.

💡 Memory Tip: Bearings start from North and move clockwise.

⚠️ Common Mistake: Do not measure anticlockwise.

Back Bearing

Back Bearing = Forward Bearing ± 180°

📖 Meaning: The opposite direction of a given bearing.

🎯 When to Use: Used when travelling between two points and returning in the opposite direction.

📝 Shortcut:

  • If bearing < 180° → Add 180°
  • If bearing ≥ 180° → Subtract 180°

💡 Memory Tip: Opposite directions differ by 180°.

⚠️ Common Mistake: Do not write more than 360°.

Distance Between Two Points (Coordinate Method)

d = √[(x₂−x₁)² + (y₂−y₁)²]

📖 Meaning: Calculates the straight-line distance between two points on a map grid.

🎯 When to Use: Used with coordinates on maps.

📝 Formula Meaning:

  • x = Easting difference
  • y = Northing difference

💡 Memory Tip: Use Pythagoras: distance is the longest side.

⚠️ Common Mistake: Use the correct order of coordinates.

Direction Angle

tan θ = Easting Difference / Northing Difference

📖 Meaning: Finds the angle of direction between two points.

🎯 When to Use: Used to calculate bearings from grid coordinates.

📝 Formula:

  • θ = tan⁻¹(Easting ÷ Northing)

💡 Memory Tip: Calculate the angle first, then identify the quadrant.

⚠️ Common Mistake: Forgetting to convert the angle into a three-digit bearing.

📂 Grid References

Four-Figure Grid Reference

4-Figure Reference = Easting + Northing

📖 Meaning: Identifies the square where a feature is located on a map.

🎯 When to Use: Used to locate large areas or map squares.

📝 Rule:

  • Read Eastings first.
  • Read Northings second.
  • "Along the corridor, then up the stairs."

💡 Memory Tip: E comes before N (Easting before Northing).

⚠️ Common Mistake: Do not read Northing before Easting.

Six-Figure Grid Reference

6-Figure Reference = Easting + Northing + Exact Position

📖 Meaning: Gives the exact location of a feature within a grid square.

🎯 When to Use: Used for precise map locations.

📝 Steps:

  • Read the two-digit Easting.
  • Estimate the third Easting digit.
  • Read the two-digit Northing.
  • Estimate the third Northing digit.

💡 Memory Tip: Six figures are more accurate than four figures.

⚠️ Common Mistake: Never reverse Easting and Northing.

Grid Square Area

Area = Length × Width

📖 Meaning: Calculates the area covered by a grid square.

🎯 When to Use: Used when measuring areas on maps.

📝 Formula Rearrangement:

  • Length = Area ÷ Width
  • Width = Area ÷ Length

💡 Memory Tip: Area always uses two dimensions.

⚠️ Common Mistake: Convert map measurements into real distances before finding actual area.

Distance from Grid Coordinates

Distance = √[(Difference in Eastings)² + (Difference in Northings)²]

📖 Meaning: Finds the straight-line distance between two grid locations.

🎯 When to Use: Used for measuring distance between mapped points.

📝 Formula Meaning:

  • Difference in Eastings = Horizontal distance
  • Difference in Northings = Vertical distance

💡 Memory Tip: This is the Pythagoras method.

⚠️ Common Mistake: Remember to apply the map scale after calculating map distance.

📂 Latitude and Longitude

Latitude Distance

Distance = Difference in Latitude × 111 km

📖 Meaning: Calculates the north-south distance between two places.

🎯 When to Use: Used to find distances along the same longitude.

📝 Formula Example:

  • 1° of latitude ≈ 111 km

💡 Memory Tip: Latitude lines are about 111 km apart.

⚠️ Common Mistake: Do not use longitude value for north-south distance.

Longitude Distance at Equator

Distance = Difference in Longitude × 111 km

📖 Meaning: Calculates east-west distance at the Equator.

🎯 When to Use: Used for places located near the Equator.

📝 Formula:

  • 1° longitude at Equator ≈ 111 km

💡 Memory Tip: Longitude spacing decreases towards the poles.

⚠️ Common Mistake: Do not use 111 km for all latitudes.

Longitude Distance at Any Latitude

Distance = Difference in Longitude × 111 × cos(latitude)

📖 Meaning: Calculates east-west distance considering Earth's curvature.

🎯 When to Use: Used for accurate longitude distance calculations away from the Equator.

📝 Formula Meaning:

  • Latitude must be in degrees.
  • cos(latitude) reduces distance towards the poles.

💡 Memory Tip: Longitude lines meet at the poles.

⚠️ Common Mistake: Forgetting the cosine factor.

Time Difference from Longitude

Time Difference = Difference in Longitude ÷ 15

📖 Meaning: Calculates time difference between places based on longitude.

🎯 When to Use: Used for calculating local time differences.

📝 Formula Rule:

  • 15° longitude = 1 hour
  • 1° longitude = 4 minutes

💡 Memory Tip: Earth rotates 360° in 24 hours.

⚠️ Common Mistake: Check whether the location is east or west before adding or subtracting time.

📂 Time Zones

Time Difference from Longitude

Time Difference = Longitude Difference ÷ 15°

📖 Meaning: Calculates the difference in local time between two places.

🎯 When to Use: Used when comparing times at different longitudes.

📝 Formula Relationship:

  • 15° longitude = 1 hour
  • 1° longitude = 4 minutes

💡 Memory Tip: The Earth rotates 15° every hour.

⚠️ Common Mistake: East is ahead in time; west is behind.

Local Time Calculation

Local Time = Given Time ± Time Difference

📖 Meaning: Finds the local time of another place using longitude difference.

🎯 When to Use: Used in world time calculations.

📝 Rule:

  • Move east → Add time
  • Move west → Subtract time

💡 Memory Tip: East increases time, west decreases time.

⚠️ Common Mistake: Forgetting to identify the direction of travel.

International Date Line Calculation

Date Change = Crossing 180° Longitude

📖 Meaning: Determines when the date changes while travelling across the International Date Line.

🎯 When to Use: Used in global travel and time zone questions.

📝 Rule:

  • Moving west across the line → Add one day
  • Moving east across the line → Subtract one day

💡 Memory Tip: The date changes at approximately 180° longitude.

⚠️ Common Mistake: Do not confuse date change with time change.

Standard Time Zone

Time Zone = Longitude ÷ 15°

📖 Meaning: Estimates the standard time zone based on longitude.

🎯 When to Use: Used to determine approximate global time zones.

📝 Formula Example:

  • 30°E ÷ 15° = UTC +2

💡 Memory Tip: Every 15 degrees represents one hour.

⚠️ Common Mistake: Real country time zones may not follow exact longitude boundaries.

📂 Gradient and Relief

Gradient

Gradient = Vertical Interval / Horizontal Equivalent

📖 Meaning: Gradient shows the steepness of a slope.

🎯 When to Use: Used in topographic maps to calculate slope steepness.

📝 Formula Rearrangement:

  • Vertical Interval = Gradient × Horizontal Equivalent
  • Horizontal Equivalent = Vertical Interval ÷ Gradient

💡 Memory Tip: Gradient compares height change with distance.

⚠️ Common Mistake: Use the same units before calculating.

Slope Percentage

% Slope = (Vertical Rise / Horizontal Distance) × 100

📖 Meaning: Shows slope steepness as a percentage.

🎯 When to Use: Used in physical geography and engineering studies.

📝 Formula Rearrangement:

  • Vertical Rise = (% Slope × Distance) ÷ 100

💡 Memory Tip: Higher percentage means a steeper slope.

⚠️ Common Mistake: Do not confuse slope percentage with gradient ratio.

Relief

Relief = Highest Elevation − Lowest Elevation

📖 Meaning: Relief is the difference between the highest and lowest points in an area.

🎯 When to Use: Used to describe the variation in land height.

📝 Formula Example:

  • Highest point = 800 m
  • Lowest point = 200 m
  • Relief = 600 m

💡 Memory Tip: Relief means height difference.

⚠️ Common Mistake: Do not add elevations together.

Vertical Interval (Contour Interval)

Contour Interval = Difference in Height / Number of Intervals

📖 Meaning: Shows the height difference between contour lines.

🎯 When to Use: Used when interpreting topographic maps.

📝 Formula:

  • Contour lines with smaller spacing indicate steep slopes.
  • Wider spacing indicates gentle slopes.

💡 Memory Tip: Same contour interval means equal height differences.

⚠️ Common Mistake: Do not count contour lines incorrectly.

📂 Contour Calculations

Contour Interval

Contour Interval = Difference in Elevation / Number of Intervals

📖 Meaning: The vertical distance between two consecutive contour lines.

🎯 When to Use: Used when interpreting relief features on topographic maps.

📝 Formula Rearrangement:

  • Difference in Elevation = Contour Interval × Number of Intervals

💡 Memory Tip: Every contour line represents equal height difference.

⚠️ Common Mistake: Count the spaces between contours, not only the lines.

Elevation of a Point

Elevation = Starting Contour Height + (Number of Intervals × Contour Interval)

📖 Meaning: Finds the height of a location on a contour map.

🎯 When to Use: Used when the exact height of a point is required.

📝 Formula Example:

  • Starting contour = 100 m
  • Interval = 20 m
  • After 3 intervals = 160 m

💡 Memory Tip: Move upward, add height; move downward, subtract height.

⚠️ Common Mistake: Check whether the point is above or below the reference contour.

Relief from Contours

Relief = Highest Contour − Lowest Contour

📖 Meaning: Calculates the total height difference shown on a contour map.

🎯 When to Use: Used to describe the terrain of an area.

📝 Formula Rearrangement:

  • Highest Height = Relief + Lowest Height

💡 Memory Tip: Relief is always the difference between high and low points.

⚠️ Common Mistake: Do not include sea level unless required.

Cross Section Scale

Vertical Exaggeration = Vertical Scale / Horizontal Scale

📖 Meaning: Shows how much the vertical height is enlarged compared with horizontal distance.

🎯 When to Use: Used when drawing topographic cross sections.

📝 Formula Rearrangement:

  • Vertical Scale = Vertical Exaggeration × Horizontal Scale

💡 Memory Tip: Vertical exaggeration makes relief easier to see.

⚠️ Common Mistake: Do not confuse vertical exaggeration with gradient.

📂 Area Calculation

Area of a Rectangle

Area = Length × Width

📖 Meaning: Calculates the surface area of rectangular regions on maps.

🎯 When to Use: Used for fields, settlements and mapped areas with regular shapes.

📝 Formula Rearrangement:

  • Length = Area ÷ Width
  • Width = Area ÷ Length

💡 Memory Tip: Rectangle area = length multiplied by width.

⚠️ Common Mistake: Convert map measurements to actual ground measurements first.

Area of a Triangle

Area = ½ × Base × Height

📖 Meaning: Calculates the area of triangular regions.

🎯 When to Use: Used when a mapped area forms a triangle.

📝 Formula Rearrangement:

  • Base = (2 × Area) ÷ Height
  • Height = (2 × Area) ÷ Base

💡 Memory Tip: Triangle is half of a rectangle with the same base and height.

⚠️ Common Mistake: Do not forget the ½ factor.

Area of a Circle

Area = πr²

📖 Meaning: Calculates the area of circular features on maps.

🎯 When to Use: Used for lakes, reservoirs or circular regions.

📝 Formula Rearrangement:

  • Radius = √(Area ÷ π)

💡 Memory Tip: Circle area uses radius squared.

⚠️ Common Mistake: Do not use diameter instead of radius.

Map Area Conversion

Actual Area = Map Area × (Scale Factor)²

📖 Meaning: Converts area measured on a map into real ground area.

🎯 When to Use: Used when calculating real land areas from maps.

📝 Formula Example:

  • Scale affects area by being squared.

💡 Memory Tip: Length uses scale once; area uses scale twice.

⚠️ Common Mistake: Do not multiply area by scale factor only.

📂 Population Density

Population Density

Population Density = Total Population / Total Land Area

📖 Meaning: Shows the number of people living per unit area of land.

🎯 When to Use: Used to compare how crowded different areas are.

📝 Formula Rearrangement:

  • Population = Density × Land Area
  • Land Area = Population ÷ Density

💡 Memory Tip: Density means people divided by space.

⚠️ Common Mistake: Use land area, not total area including water.

Arithmetic Population Density

Arithmetic Density = Total Population / Total Area

📖 Meaning: Measures the average number of people per square kilometre.

🎯 When to Use: Used for general population comparisons between countries or regions.

📝 Unit:

  • People per km²

💡 Memory Tip: It is the simplest population density calculation.

⚠️ Common Mistake: Do not confuse with agricultural density.

Agricultural Density

Agricultural Density = Rural Population / Arable Land Area

📖 Meaning: Shows the number of farmers per unit of productive farmland.

🎯 When to Use: Used to study pressure on agricultural land.

📝 Unit:

  • Farmers per km² of arable land

💡 Memory Tip: Agriculture density focuses on farmers and farmland.

⚠️ Common Mistake: Do not use total land area.

Physiological Density

Physiological Density = Total Population / Arable Land Area

📖 Meaning: Shows population pressure on usable farmland.

🎯 When to Use: Used to measure food production pressure.

📝 Unit:

  • People per km² of arable land

💡 Memory Tip: Physiological = people depending on farmland.

⚠️ Common Mistake: Do not divide by total land area.

📂 Population Growth Rate

Natural Increase Rate

Natural Increase Rate = Birth Rate − Death Rate

📖 Meaning: Shows the population change caused by births and deaths only.

🎯 When to Use: Used to measure population growth without migration.

📝 Unit:

  • Usually expressed as percentage (%) or per thousand (‰).

💡 Memory Tip: Births increase population; deaths reduce population.

⚠️ Common Mistake: Do not include migration in natural increase.

Population Growth Rate

Growth Rate = (Birth Rate − Death Rate + Net Migration Rate)

📖 Meaning: Shows the total change in population including migration.

🎯 When to Use: Used to calculate actual population growth.

📝 Formula:

  • Positive value = Population increase
  • Negative value = Population decrease

💡 Memory Tip: Growth = Natural Increase + Migration.

⚠️ Common Mistake: Remember to include migration when asked for total growth.

Percentage Population Growth

% Growth = (New Population − Original Population) / Original Population × 100

📖 Meaning: Shows the percentage increase or decrease in population over time.

🎯 When to Use: Used when comparing population changes between years.

📝 Formula Rearrangement:

  • Population Change = New Population − Original Population

💡 Memory Tip: Percentage change is always compared with the original value.

⚠️ Common Mistake: Do not divide by the new population.

Doubling Time (Rule of 70)

Doubling Time = 70 / Annual Growth Rate (%)

📖 Meaning: Estimates how long it takes for a population to double.

🎯 When to Use: Used for population prediction.

📝 Formula Example:

  • Growth rate = 2%
  • Doubling time = 70 ÷ 2 = 35 years

💡 Memory Tip: Divide 70 by the growth percentage.

⚠️ Common Mistake: Use percentage growth, not decimal form.

📂 Birth Rate and Death Rate

Crude Birth Rate (CBR)

CBR = (Number of Live Births / Total Population) × 1000

📖 Meaning: Shows the number of live births per 1,000 people in a year.

🎯 When to Use: Used to compare birth levels between populations.

📝 Unit:

  • Births per 1,000 people per year (‰)

💡 Memory Tip: Births ÷ population × 1000.

⚠️ Common Mistake: Do not multiply by 100 instead of 1000.

Crude Death Rate (CDR)

CDR = (Number of Deaths / Total Population) × 1000

📖 Meaning: Shows the number of deaths per 1,000 people in a year.

🎯 When to Use: Used to compare mortality levels between populations.

📝 Unit:

  • Deaths per 1,000 people per year (‰)

💡 Memory Tip: Deaths ÷ population × 1000.

⚠️ Common Mistake: Use total population as the denominator.

Infant Mortality Rate (IMR)

IMR = (Infant Deaths Under 1 Year / Live Births) × 1000

📖 Meaning: Shows deaths of infants before reaching one year old.

🎯 When to Use: Used as an indicator of healthcare quality.

📝 Unit:

  • Deaths per 1,000 live births

💡 Memory Tip: Infant deaths are compared with births, not total population.

⚠️ Common Mistake: Do not use total deaths in the formula.

Fertility Rate

General Fertility Rate = (Number of Births / Number of Women Aged 15–49) × 1000

📖 Meaning: Measures births among women of reproductive age.

🎯 When to Use: Used for detailed population studies.

📝 Unit:

  • Births per 1,000 women aged 15–49

💡 Memory Tip: Fertility focuses on women of childbearing age.

⚠️ Common Mistake: Do not use total female population.

📂 Migration Calculations

Net Migration

Net Migration = Number of Immigrants − Number of Emigrants

📖 Meaning: Shows the difference between people entering and leaving an area.

🎯 When to Use: Used to measure the effect of migration on population.

📝 Formula Meaning:

  • Positive value = More people entering
  • Negative value = More people leaving

💡 Memory Tip: Immigration adds; emigration removes.

⚠️ Common Mistake: Do not reverse immigrants and emigrants.

Net Migration Rate

NMR = (Immigrants − Emigrants) / Total Population × 1000

📖 Meaning: Shows migration change per 1,000 people.

🎯 When to Use: Used to compare migration between countries or regions.

📝 Unit:

  • Migrants per 1,000 people per year

💡 Memory Tip: Net migration divided by population.

⚠️ Common Mistake: Multiply by 1000, not 100.

Migration Balance

Migration Balance = Immigration − Emigration

📖 Meaning: Shows whether an area gains or loses population through migration.

🎯 When to Use: Used in population change calculations.

📝 Formula:

  • Positive balance = Population gain
  • Negative balance = Population loss

💡 Memory Tip: Balance means the difference between in and out.

⚠️ Common Mistake: Do not include births and deaths.

Total Population Change

Population Change = (Births − Deaths) + (Immigration − Emigration)

📖 Meaning: Calculates total population change including natural change and migration.

🎯 When to Use: Used for complete population change analysis.

📝 Formula:

  • Natural Change = Births − Deaths
  • Migration Change = Immigration − Emigration

💡 Memory Tip: Population change has two parts: natural and migration.

⚠️ Common Mistake: Do not ignore migration when calculating total change.

📂 Urbanization Statistics

Urbanization Rate

Urbanization Rate = (Urban Population / Total Population) × 100

📖 Meaning: Shows the percentage of people living in urban areas.

🎯 When to Use: Used to measure the level of urban development.

📝 Formula Rearrangement:

  • Urban Population = (Urbanization Rate × Total Population) ÷ 100

💡 Memory Tip: Urban percentage = city population divided by total population.

⚠️ Common Mistake: Do not use rural population as the denominator.

Urban Growth Rate

Urban Growth Rate = (New Urban Population − Old Urban Population) / Old Urban Population × 100

📖 Meaning: Measures how quickly an urban population increases.

🎯 When to Use: Used to study city expansion over time.

📝 Formula:

  • Positive value = Urban growth
  • Negative value = Urban decline

💡 Memory Tip: Growth compares the change with the original population.

⚠️ Common Mistake: Divide by the old population, not the new population.

Population Concentration

Concentration = Population in Area / Total Population × 100

📖 Meaning: Shows the proportion of people concentrated in a particular area.

🎯 When to Use: Used to analyse population distribution in cities and regions.

📝 Formula:

  • Higher percentage means greater concentration.

💡 Memory Tip: Concentration measures how crowded a specific area is.

⚠️ Common Mistake: Do not confuse concentration with density.

Urban Density

Urban Density = Urban Population / Urban Area

📖 Meaning: Shows the number of people living per unit area in a city.

🎯 When to Use: Used to study overcrowding and city planning.

📝 Unit:

  • People per km²

💡 Memory Tip: Density always compares people with space.

⚠️ Common Mistake: Use urban area, not total country area.

📂 Agriculture Calculations

Crop Yield

Crop Yield = Total Crop Production / Cultivated Area

📖 Meaning: Shows the amount of crop produced per unit area of farmland.

🎯 When to Use: Used to measure agricultural productivity.

📝 Formula Rearrangement:

  • Crop Production = Crop Yield × Cultivated Area
  • Cultivated Area = Crop Production ÷ Yield

💡 Memory Tip: Yield means output from a given area.

⚠️ Common Mistake: Do not divide by total land area instead of cultivated area.

Land Use Percentage

% Land Use = (Area Used for Purpose / Total Land Area) × 100

📖 Meaning: Shows the proportion of land used for a specific activity.

🎯 When to Use: Used to analyse farming, settlement and conservation areas.

📝 Formula Rearrangement:

  • Area Used = (% Land Use × Total Area) ÷ 100

💡 Memory Tip: Part divided by whole gives percentage.

⚠️ Common Mistake: Use the correct total land area.

Agricultural Productivity

Productivity = Agricultural Output / Input Used

📖 Meaning: Measures how efficiently resources produce agricultural output.

🎯 When to Use: Used to compare farming efficiency.

📝 Examples of Inputs:

  • Labour
  • Fertilizer
  • Water
  • Machinery

💡 Memory Tip: Productivity = what you get compared with what you use.

⚠️ Common Mistake: Do not confuse productivity with total production.

Food Production Per Capita

Food Production Per Capita = Total Food Production / Total Population

📖 Meaning: Shows the average food available per person.

🎯 When to Use: Used in food security studies.

📝 Formula:

  • Higher value indicates greater food availability.

💡 Memory Tip: Per capita means "per person".

⚠️ Common Mistake: Do not divide by land area.

📂 Climate Calculations (Temperature & Rainfall)

Mean Temperature

Mean Temperature = Sum of Temperatures / Number of Readings

📖 Meaning: Calculates the average temperature over a period of time.

🎯 When to Use: Used for daily, monthly or annual temperature analysis.

📝 Formula Rearrangement:

  • Total Temperature = Mean Temperature × Number of Readings

💡 Memory Tip: Average means total divided by number.

⚠️ Common Mistake: Do not divide by the wrong number of readings.

Annual Temperature Range

Annual Temperature Range = Highest Temperature − Lowest Temperature

📖 Meaning: Shows the difference between the hottest and coldest temperatures in a year.

🎯 When to Use: Used to compare climate variations between places.

📝 Formula Example:

  • Highest = 32°C
  • Lowest = 18°C
  • Range = 14°C

💡 Memory Tip: Range is always maximum minus minimum.

⚠️ Common Mistake: Do not add temperatures together.

Mean Annual Rainfall

Mean Annual Rainfall = Total Annual Rainfall / Number of Years

📖 Meaning: Calculates the average rainfall received over several years.

🎯 When to Use: Used in climate classification and comparison.

📝 Unit:

  • Millimetres (mm)

💡 Memory Tip: Rainfall average uses the same method as temperature average.

⚠️ Common Mistake: Ensure all rainfall values use the same unit.

Rainfall Percentage Contribution

% Rainfall Contribution = (Rainfall in Period / Total Rainfall) × 100

📖 Meaning: Shows how much rainfall occurs in a particular month or season.

🎯 When to Use: Used when analysing seasonal rainfall patterns.

📝 Formula:

  • Higher percentage means greater rainfall contribution.

💡 Memory Tip: Part divided by total gives percentage.

⚠️ Common Mistake: Do not use the wrong total rainfall value.

📂 Weather Statistics

Temperature Average

Average Temperature = Total Temperature Readings / Number of Readings

📖 Meaning: Calculates the average temperature recorded over a period.

🎯 When to Use: Used when analysing daily or monthly weather data.

📝 Formula Rearrangement:

  • Total Temperature = Average × Number of Readings

💡 Memory Tip: Add all readings, then divide.

⚠️ Common Mistake: Do not forget negative temperatures when calculating.

Temperature Range

Temperature Range = Maximum Temperature − Minimum Temperature

📖 Meaning: Shows the difference between the highest and lowest temperatures.

🎯 When to Use: Used to measure temperature variation.

📝 Formula Example:

  • Maximum = 35°C
  • Minimum = 20°C
  • Range = 15°C

💡 Memory Tip: Range = highest minus lowest.

⚠️ Common Mistake: Do not use average temperature for range.

Rainfall Average

Average Rainfall = Total Rainfall / Number of Periods

📖 Meaning: Finds the average amount of rainfall over a given time.

🎯 When to Use: Used in rainfall analysis and climate studies.

📝 Unit:

  • Millimetres (mm)

💡 Memory Tip: Rainfall averages follow the same rule as other averages.

⚠️ Common Mistake: Keep all rainfall measurements in the same unit.

Relative Humidity

Relative Humidity = (Actual Water Vapour / Maximum Water Vapour Capacity) × 100

📖 Meaning: Shows the amount of moisture in the air compared with the maximum possible amount.

🎯 When to Use: Used in weather and climate studies.

📝 Unit:

  • Percentage (%)

💡 Memory Tip: Humidity compares actual moisture with possible moisture.

⚠️ Common Mistake: Do not reverse the numerator and denominator.

📂 Economic Geography Calculations

Gross Domestic Product (GDP) Per Capita

GDP Per Capita = GDP / Total Population

📖 Meaning: Shows the average economic output per person in a country.

🎯 When to Use: Used to compare economic development between countries.

📝 Formula Rearrangement:

  • GDP = GDP Per Capita × Population

💡 Memory Tip: Per capita means "per person".

⚠️ Common Mistake: Do not divide by land area.

Employment Rate

Employment Rate = (Number of Employed People / Working Age Population) × 100

📖 Meaning: Shows the percentage of working-age people who are employed.

🎯 When to Use: Used to study labour markets.

📝 Formula:

  • Higher percentage indicates more employment.

💡 Memory Tip: Employed people divided by available workers.

⚠️ Common Mistake: Do not use total population as the denominator.

Unemployment Rate

Unemployment Rate = (Number of Unemployed People / Labour Force) × 100

📖 Meaning: Shows the percentage of people without jobs but seeking work.

🎯 When to Use: Used to measure economic conditions.

📝 Formula Rearrangement:

  • Unemployed People = (Rate × Labour Force) ÷ 100

💡 Memory Tip: Unemployment focuses on people looking for work.

⚠️ Common Mistake: Do not include children or retired people in labour force.

Trade Balance

Trade Balance = Value of Exports − Value of Imports

📖 Meaning: Shows whether a country exports more than it imports.

🎯 When to Use: Used in economic and trade analysis.

📝 Formula Meaning:

  • Positive = Trade surplus
  • Negative = Trade deficit

💡 Memory Tip: Exports add, imports subtract.

⚠️ Common Mistake: Do not reverse imports and exports.

📂 Transport and Trade Calculations

Transport Density

Transport Density = Total Length of Transport Network / Total Area

📖 Meaning: Measures the availability of transport routes in an area.

🎯 When to Use: Used to compare transport development between regions.

📝 Unit:

  • km of transport route per km²

💡 Memory Tip: More routes in a smaller area means higher density.

⚠️ Common Mistake: Use the correct total area.

Traffic Flow

Traffic Flow = Number of Vehicles / Time Period

📖 Meaning: Shows the number of vehicles passing a point over a period of time.

🎯 When to Use: Used in transport studies and road surveys.

📝 Unit:

  • Vehicles per hour/day

💡 Memory Tip: Flow means movement over time.

⚠️ Common Mistake: Do not forget the time unit.

Average Travel Speed

Speed = Distance / Time

📖 Meaning: Calculates how fast transport moves between two locations.

🎯 When to Use: Used in transport efficiency calculations.

📝 Formula Rearrangement:

  • Distance = Speed × Time
  • Time = Distance ÷ Speed

💡 Memory Tip: Speed = how far divided by how long.

⚠️ Common Mistake: Use matching units for distance and time.

Trade Volume

Trade Volume = Exports + Imports

📖 Meaning: Shows the total amount of goods traded internationally.

🎯 When to Use: Used to measure the size of trade activity.

📝 Formula:

  • Total Trade = Goods Sold Abroad + Goods Bought Abroad

💡 Memory Tip: Volume includes both directions of trade.

⚠️ Common Mistake: Do not subtract imports from exports.

📂 Environmental Geography Calculations

Carbon Footprint

Carbon Footprint = Total Greenhouse Gas Emissions

📖 Meaning: Measures the amount of carbon dioxide and other greenhouse gases produced by an activity, person, or organisation.

🎯 When to Use: Used to study environmental impact and climate change.

📝 Formula Components:

  • Energy use emissions
  • Transport emissions
  • Industrial emissions

💡 Memory Tip: Carbon footprint means the environmental "mark" left behind.

⚠️ Common Mistake: Do not measure only carbon dioxide if other greenhouse gases are included.

Deforestation Rate

Deforestation Rate = (Area of Forest Lost / Original Forest Area) × 100

📖 Meaning: Shows the percentage of forest area lost over a period of time.

🎯 When to Use: Used to analyse forest destruction and environmental change.

📝 Formula Rearrangement:

  • Forest Lost = (Deforestation Rate × Original Forest Area) ÷ 100

💡 Memory Tip: Lost forest is compared with the original forest.

⚠️ Common Mistake: Do not divide by the remaining forest area.

Waste Recycling Rate

Recycling Rate = (Amount Recycled / Total Waste Produced) × 100

📖 Meaning: Shows the percentage of waste that is recycled.

🎯 When to Use: Used to measure environmental management success.

📝 Formula:

  • Higher percentage means better recycling performance.

💡 Memory Tip: Recycled waste is the useful part of total waste.

⚠️ Common Mistake: Do not use total landfill waste as the denominator.

Water Consumption Per Capita

Water Consumption Per Capita = Total Water Used / Total Population

📖 Meaning: Shows the average amount of water used per person.

🎯 When to Use: Used in studies of water resources and sustainability.

📝 Unit:

  • Litres per person per day (L/person/day)

💡 Memory Tip: Per capita always means per person.

⚠️ Common Mistake: Do not divide by land area.
